01 — What we learned

The best work is quiet, with one idea that does a job.

Every reference was analysed by looking at its pixels: hexes sampled, contrast computed, motion measured. These six findings shape the skill.

1+1

One base, one expressive layer

Top references pair a restrained structure with exactly one expressive device. Stacking glass, aurora and gradient-mesh produced the lowest scores.

0.33s

Motion has a house style

Median UI transition across 1,368 measured moves. 44% ease out; menus open 1.5–3× slower than they close.

1.17

Real type scales are gentle

Median step ratio on live sites, with a 15–16px body. Display runs about 3.75× body; tracking tightens to −0.01 to −0.03em.

89%

Contrast is the blind spot

Ship text below AA. Judges barely penalised it (6.64 vs 6.68 usability), so the skill measures contrast instead of judging it.

2–3

Radius systems are small

Pill, one card radius and a nested inner radius. Zero is reserved for things that should feel like paper.

4/348

States are the gap

Only four references show an empty, error or 404 state, and none a reduced-motion variant. The happy path is over-designed.

02 — The method

Six steps, in order. The last one loops.

The skill is procedural on purpose: tokens are committed before any component, and nothing ships until it has been rendered and looked at.

  1. Read the brief

    Audience, job, real content, three tone words — and one signature moment.

  2. Choose a direction

    One structural base, one expressive layer, a characterful display voice.

  3. Commit tokens

    Colour roles, type scale, radii, motion — every text pair verified for contrast.

  4. Lay out & set type

    12-column grid, one focal point, measure ≤ 72ch, tabular numbers.

  5. Build every state

    Hover, focus, active, disabled, loading, error, empty — and reduced motion.

  6. Render, audit, iterate

    Screenshots at 390 / 768 / 1440, six hard gates, a rubric score, three fixes.

Stops when every gate passes and every axis scores ≥ 7 — or after three loops, with what's left reported honestly.

03 — Evidence

Blind-tested against the same model without it.

Five briefs, built twice by the same model. Fresh graders scored both versions as A and B, without knowing which used the skill.

With skill · hard gates passed30/30
Without · hard gates passed18/30

Gates: AA contrast, no overflow at 390px, visible keyboard focus, reduced motion, text ≥ 12px, alt text and names. Mean raw score 64.0 vs 50.2. Caveats are published with the results: one build per arm, model graders, about ±6 points of grader noise — smaller than every margin.
